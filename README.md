# Expense Tracker – Django Web Application

Expense Tracker is a web-based application developed using **Django** that helps users manage and track their daily expenses efficiently.  
The application allows users to record income and expenses, categorize transactions, and view spending history.

This project focuses on understanding CRUD operations, user authentication, and backend logic using Django.

---

## 🚀 Features
- User authentication (Register & Login)
- Add income and expenses
- View expense history
- Edit & delete transactions

---

## 🛠️ Technologies Used
- Python
- Django
- HTML5
- CSS3
- Bootstrap
- SQLite Database
